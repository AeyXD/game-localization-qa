# Checklist ตรวจคำแปลก่อนส่งมอบ (Pre-Delivery QA Checklist)

> ใช้ตรวจรอบสุดท้ายทุกไฟล์ก่อนส่งทีม/ผู้ใช้ — ปรับปรุงจากมาตรฐานการแปลระดับโปรเจกต์จริง ใช้ได้กับทุกเกม

## 1. ความถูกต้องเชิงเนื้อหา
- [ ] ความหมาย เงื่อนไข และ Logic ตรงตามต้นฉบับ 100%
- [ ] เนื้อหาครบ โดยไม่จำเป็นต้องแปลทุกคำหรือเรียงตามโครงภาษาอังกฤษ
- [ ] ระดับความแน่นอนถูกคงไว้ ("อาจ" ไม่กลายเป็น "จะ")
- [ ] ตัวเลข หน่วย ระยะเวลา และกลไกเกมครบถ้วน
- [ ] ไม่เติม Spoiler หรือข้อมูลที่ต้นฉบับไม่มี

## 2. ภาษาและบุคลิก
- [ ] อ่านลื่นไหล เป็นธรรมชาติ ไม่ห้วนหรือกำกวมจากการย่อ
- [ ] ตัดคำซ้ำจากการแปล แต่คงการซ้ำที่สื่ออารมณ์/บุคลิกของผู้พูด
- [ ] สรรพนามถูกบุคลิกและความสัมพันธ์ สม่ำเสมอทั้งฉากและทั้งเกม
- [ ] "คุณ" ใช้เฉพาะเสียงของระบบ (UI/บทช่วยสอน) — บทสนทนาเลือกตามบุคลิก
- [ ] น้ำเสียงเหมาะกับประเภทข้อความ (ตามตาราง Message-Type Register ใน pillar-2)
- [ ] ตัวเลือกบทสนทนาสื่อเจตนาชัด ไม่เปลี่ยนน้ำหนักจนผู้เล่นเข้าใจผิด

## 3. ความสม่ำเสมอและศัพท์
- [ ] ใช้ศัพท์ตรงตามคลัง/Glossary ของโปรเจกต์ทั้งเกม
- [ ] ชื่อเควสต์/ไอเท็ม/สถานที่/ตัวละครสะกดตรงกันทุกจุดที่ปรากฏ
- [ ] ศัพท์เทคนิคใช้อังกฤษหรือทับศัพท์อย่างสม่ำเสมอเมื่อชัดกว่าคำไทย

## 4. การจัดรูปแบบและความปลอดภัยไฟล์
- [ ] ไม้ยมกเว้นวรรคถูกต้อง · เสียงหัวเราะเขียนเต็มคำ · `ป.ล.` · จุดไข่ปลา/ประโยคค้างตามต้นฉบับ
- [ ] รักษาชื่อเฉพาะ ตัวแปร แท็ก และ Syntax ของเกมครบ (รวม `[DEBUG]` และสตริงผู้พัฒนาที่ไม่ต้องแปล)
- [ ] จำนวนบรรทัด/แท็ก/encoding เท่าต้นฉบับเป๊ะ
- [ ] รัน `python3 checker/thai_qa.py <ไฟล์> --fix --report review.csv` แล้วไม่เหลือปัญหาระดับ error

## 5. ขั้นสุดท้าย
- [ ] ตรวจแก้งานเดิมแบบ minimal diff: เก็บประโยคที่ดีอยู่แล้ว แก้เฉพาะจุดที่ผิดเกณฑ์
- [ ] บันทึกกับดักใหม่ที่เจอลง `data/*.json` ตาม Self-Upgrade Protocol
