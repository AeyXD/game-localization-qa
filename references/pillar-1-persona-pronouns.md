# เสาหลักที่ 1: สารบบตัวละคร สรรพนาม และลำดับชั้นความสัมพันธ์ (Persona & Pronoun Matrix)

> 📂 ข้อมูลเชิงโครงสร้างฉบับเต็ม: `data/pronouns-matrix.json`

## 1. ขจัดปัญหากฎคำพูดทหารเหมารวม (Eradicate the Military Blanket Rule)

- ❌ **ข้อห้ามเด็ดขาด:** ห้ามให้ตัวละครหญิง อัศวินหญิง หรือเจ้าหน้าที่หญิงพูดลงท้ายด้วย "ผม/ครับ" หรือใช้สรรพนามชายโดยอ้างว่าเป็นบททหาร
- ✅ **การปรับใช้:** ตรวจสอบเพศ สถานะทางสังคม และความสัมพันธ์ของตัวละครทุกครั้งก่อนกำหนดสรรพนาม

## 2. เมทริกซ์สรรพนามตามบริบทและยุคสมัย (Era & Relationship Matrix)

**แนวแฟนตาซี / ยุคกลาง (High Fantasy / Medieval):**
- ระหว่างสหาย / นักรบ: `ข้า` - `เจ้า`
- ต่อผู้มีฐานันดรสูง / กษัตริย์: `ข้าพระพุทธเจ้า` / `ข้า` - `ฝ่าบาท` / `ท่าน` / `ใต้เท้า`
- ตัวละครหญิงพูดกับคนสนิท: `ฉัน` - `นาย` / `ข้า` - `ท่าน`
- ผู้รับใช้ / พอว์น ต่อเจ้านาย: `ข้า` / `ข้าพเจ้า` - `นายท่าน` (Master ❌ **ห้ามแปลว่า "อาจารย์"** ในบริบท Pawn/Servant)

**แนวไซไฟ / ยุคใหม่ / การทหาร (Modern / Sci-Fi / Military):**
- เจ้าหน้าที่วิทยุ / AWACS: `ฉัน` / `ทางนี้` - `คุณ` / `ทุกหน่วย`
- ทหารชาย: `ผม` / `ฉัน` - `ผู้หมวด` / `ผู้กอง` / `ท่าน`

**แนวร่วมสมัย / เพื่อนร่วมแก๊ง (Modern Urban / Casual):**
- เพื่อนสนิท: `ฉัน` - `แก` / `ฉัน` - `นาย` / `กู` - `มึง` (ตามระดับเรตติ้งของเกม)

## 3. เสียงของระบบ (System Voice): บทช่วยสอนและคำอธิบาย UI

> 📂 ข้อมูลเชิงโครงสร้างฉบับเต็ม: `data/pronouns-matrix.json` → `system_voice`

เสียง "ตัวเกมพูดกับผู้เล่น" ต่างจากเสียงตัวละคร — ไม่ผูกเพศหรือยุคสมัย แต่ผูก**ความสม่ำเสมอทั้งเกม** และเป็นข้อความที่ผู้เล่นเห็นบ่อยที่สุด (ทุกปุ่ม ทุกแจ้งเตือน ทุก tutorial):

- **ค่าเริ่มต้นคือ "คุณ"** (กลาง สุภาพ ปลอดภัยทุกเรตติ้ง): `คุณได้รับชุดเกราะใหม่`, `คุณได้ปลดล็อกด่านใหม่`
- **ปุ่ม/ป้ายสั้นมากให้ตัดประธาน** (ประหยัดงบตัวอักษร UI ตามเสาหลัก 6): `บันทึกเกม`, `ยกเลิก`, `ได้รับไอเท็ม`
- **คำสั่งใน tutorial ใช้กริยาล้วนได้**: `กด X เพื่อกระโดด`, `ลากไอเท็มไปที่ช่อง`
- **ข้อความต้อนรับใช้ชื่อผู้เล่นได้**: `ยินดีต้อนรับ {player}`
- 🛑 **กฎเหล็ก 3 ข้อ:**
  1. เลือกหนึ่งรูปแล้วสม่ำเสมอ 100% ทั้งเกม — ห้ามสลับ คุณ/เธอ/ท่าน ปนกันใน UI ด้วยกัน
  2. ห้ามบุรุษที่ 1 ในบทระบบ (❌ `ฉันต้องกด X เพื่อกระโดด` — MT เติมประธาน I ให้ต้นฉบับที่ไม่มีประธาน) — ตัวเกมไม่ใช่ตัวผู้เล่น
  3. เกมที่มีผู้บรรยายเฉพาะตัว (ครูฝึก/คู่หู AI/ผู้เล่าเรื่อง) ใช้เสียงอื่นได้ตาม style guide ของโปรเจกต์ แต่ต้องสม่ำเสมอเช่นกัน

## 4. กฎเสริมเสาหลักที่ 1 (จากมาตรฐานโปรเจกต์จริง)

- **ความสม่ำเสมอระดับฉาก (Scene Consistency):** ผู้พูดคนเดียวกันเรียกผู้ฟังคนเดียวกันด้วยสรรพนามเดียวกัน**ตลอดทั้งฉาก** — เปลี่ยนได้เฉพาะเมื่อท่าที/ความสัมพันธ์เปลี่ยนตามเนื้อเรื่องอย่างชัดเจน
- **บุคลิกอนุญาตข้อยกเว้นได้ (Persona Exception):** ตัวละครบางบุคลิก (กวีเจ้าสำราญ ทูต คนพื้นเมือง) ใช้สรรพนามพิเศษที่คนอื่นใช้ไม่ได้ เช่น "นาย" — ได้เมื่อมีเหตุผลจากบุคลิก และใช้สม่ำเสมอทั้งเกม
- **ตารางสรรพนามระดับโปรเจกต์ (Project Pronoun Sheet):** เมื่อทำเกมเฉพาะ ให้สร้างตารางรูป **ผู้พูด → ผู้ฟัง** พร้อมคอลัมน์ **ใช้ / ไม่ใช้** (ระบุฝั่ง "ไม่ใช้" ด้วย เช่น ห้าม "คุณ" ในบทแฟนตาซียุคกลาง) แล้วใช้เป็นคลังเดียวทั้งทีมตลอดโปรเจกต์
