# เสาหลักที่ 2: ขัดเกลากิริยาบทและบริบท (Context, Mannerisms & Tone Polish)

> 📂 บัญชีสำนวนฉบับเต็ม: `data/mt-traps.json` (category: `idiom`)

## 1. ขจัดสำนวนแปลตรงตัวแข็งทื่อ (Anti-Literal Translation)

ปรับเปลี่ยนโครงสร้างประโยคแบบภาษาอังกฤษที่ขึ้นต้นด้วยกรรมหรือคำเชื่อมฟุ่มเฟือย ให้เป็นภาษาพูดธรรมชาติที่ "เข้าปากและสละสลวย":

- `"It is not impossible that..."` ➔ `"อาจมีหนทางอยู่..."` (❌ `"มันไม่ได้เป็นไปไม่ได้ที่..."`)
- `"There is no doubt that..."` ➔ `"เห็นได้ชัดว่า..."` / `"แน่นอนว่า..."` (❌ `"ไม่มีข้อสงสัยเลยว่า..."`)

## 2. การแปลงสำนวนอุปมาอุปไมย (Idiomatic Transcreation)

ห้ามแปลสำนวนภาษาอังกฤษแบบคำต่อคำ ให้แปลงเป็นสำนวนภาษาไทยที่มีน้ำหนักและความหมายเทียบเท่า ตัวอย่างเปิดแนวทาง (รายการเต็มดูใน data file):

- `Bite the bullet` ➔ **"กัดฟันสู้"** / **"ยอมรับชะตากรรม"** (❌ "กัดกระสุน")
- `'Twixt a rock and a hard place` ➔ **"กลืนไม่เข้าคายไม่ออก"** (❌ "ระหว่างหินกับที่แคบ")
- `Draw fire / Draw their fire` ➔ **"ล่อเป้า"** / **"ดึงความสนใจศัตรู"** (❌ "ยิงไฟ" / "วาดไฟ")
- `I call shotgun!` (Seating Slang) ➔ **"ฉันขอนั่งเบาะหน้า!"** (❌ "ฉันเรียกปืนลูกซอง!")
- `Sic Parvis Magna` (Motto) ➔ **"จากจุดเริ่มต้นเล็ก ๆ สู่ความยิ่งใหญ่ (Sic Parvis Magna)"**

**กฎการเพิ่มสำนวนใหม่:** เมื่อพบ idiom ใหม่ให้ append ลง `data/mt-traps.json` (category: `idiom`) พร้อมทั้งรูปถูก (correct) และรูปแปลตรงตัวที่ผิด (forbidden) เสมอ

## 3. การตรวจสอบวัฒนธรรมและความอ่อนไหว (Cultural & Sensitivity Review)

มาตรฐาน LQA สากลกำหนดให้ตรวจคอนเทนต์ตามเรตติ้งของเกมและความอ่อนไหวของตลาดปลายทางก่อนส่งมอบเสมอ:

- **ระดับภาษาตามเรตติ้ง (Rating-Aware Register):** ทั่วไป/G (ห้ามคำหยาบทุกรูป ใช้ "บ้า"/"โธ่"/"นี่แฮะ") | 13+/15+ (คำอุทานอ่อน เช่น "เฮ้ย" ได้ตามต้นฉบับ) | 18+/Mature (`กู-มึง` และคำหยาบตามต้นฉบับได้ แต่ต้องหนักแน่นสม่ำเสมอทั้งเกม — ห้ามช่วงต้นสุภาพแล้วช่วงหลังหนักเอาดื้อ ๆ)
- **หัวข้อต้องแจ้งธงสำหรับตลาดไทย (Flag Topics):** การเสียดสี/ล้อสถาบันหลักของชาติ, การใช้พระพุทธศาสนา ศาสนสถาน หรือพระคัมภีร์ในบริบทไม่เหมาะสม (เช่น ปรากฏในฉากสยองขวัญหรือเป็นอาวุธ — เคยมีเกมถูกทวงคืนจากตลาดไทยจริง), ธงชาติและสัญลักษณ์แผ่นดิน, การล้อประวัติศาสตร์ไทยผิดเพี้ยน, ความรุนแรงต่อเด็ก, การชูยาเสพติดในเชิงบวก
- **LGBTQ+ และเพศสภาพ:** แปลตามต้นฉบับอย่างเคารพ ห้ามเซ็นเซอร์หรือเปลี่ยนคำสรรพนามเพศเองโดยไม่มีเหตุผลจากต้นฉบับ
- 🛑 **กฎเหล็ก:** ห้าม AI หรือนักแปล "แก้/ตัด/หน่วง" เนื้อหาอ่อนไหวเอง — ให้ Flag พร้อมบริบทเต็ม (row ไหน ไฟล์ไหน ภาพประกอบ) ส่งให้ LQA Lead และ Publisher เป็นผู้ตัดสินร่วมกับทีมกฎหมาย เพราะกระทบ compliance ระดับประเทศ

## 4. หลักการแปลกลาง (Universal Translation Principles)

> แนวทางเชิงหลักการที่ใช้ได้กับทุกเกม (ปรับปรุงจากมาตรฐานการแปลระดับโปรเจกต์จริง)

- **แปลความ ไม่จำเป็นต้องแปลทุกคำ:** อ่านทั้งประโยค/ทั้งช่วงก่อนแปล ไม่จับคู่อังกฤษ-ไทยทีละคำ — ปรับลำดับ รวมความ หรือละคำที่ภาษาไทยไม่จำเป็นได้ โดยไม่ตัดสาระสำคัญหรือเติมความหมายใหม่
- **รักษาระดับความแน่นอน (Modality):** "อาจ" ห้ามกลายเป็น "จะ" — คงความไม่แน่นอน การปฏิเสธ ข้อยกเว้น เงื่อนไข และลำดับเหตุการณ์ตามต้นฉบับ
- **คงตัวเลข หน่วย ระยะเวลา และรายละเอียดกลไกเกมให้ครบ** แม้จะปรับโครงสร้างประโยค
- **แยก "การซ้ำที่ตั้งใจ" ออกจาก "คำซ้ำจากการแปลตรงตัวทุกคำ":** การพูดซ้ำ การลังเล หรือถ้อยคำขาดห้วงที่สื่ออารมณ์/บุคลิกต้องคงไว้ทุกตัว — ตัดเฉพาะคำซ้ำที่ภาษาไทยไม่จำเป็นต้องมี ซึ่งเกิดจากการลากโครงสร้างอังกฤษมาทุกคำ (เช่น ประธานซ้ำ "ชายคนนั้น เขากล่าวว่า", คำเชื่อม and/then ทุกตัว, การอ้างสถานที่เดิมซ้ำ "ที่หอคอยนั้น")
  - ตัวชี้ขาด: ถ้าอังกฤษ*ไม่ได้ซ้ำ*แต่ไทยซ้ำ หรือตัดออกแล้วความหมายและอารมณ์*ไม่เปลี่ยน* = ตัดได้ | ถ้าตัดแล้ว*เสียอารมณ์หรือบุคลิก* (เช่น "ไม่... ไม่ ไม่ ไม่" ของคนตกใจ) = ตั้งใจของผู้เขียน ต้องคงไว้
- **ตัวเลือกบทสนทนา (Dialogue Choices):** สื่อเจตนาให้ชัดทั้งยอมรับ ปฏิเสธ ข่มขู่ ต่อรอง — ห้ามเปลี่ยนน้ำหนักจนผู้เล่นเข้าใจสิ่งที่กำลังจะเลือกผิด และคงความคลุมเครือทางศีลธรรม/เบาะแสที่ต้นฉบับวางไว้
- **คงมุมมองของผู้พูด:** อคติ คำโกหก หรือคำโฆษณาชวนเชื่อของตัวละครต้องคงสภาพเดิม — ห้าม "แก้ให้เป็นความจริงกลาง"
- **ข้อความประชาสัมพันธ์:** ปรับให้ชวนอ่านได้ แต่ห้ามเติมคำโอ้อวดหรือข้อเสนอที่ต้นฉบับไม่ได้ระบุ (เช่น "ฟรี")
- **เมื่อตรวจแก้งานเดิม:** เก็บประโยคที่ดีอยู่แล้ว แก้เฉพาะจุดที่ไม่ตรงเกณฑ์ — ห้ามเขียนใหม่ทั้งประโยคเพียงเพราะอยากให้ต่างจากเดิม (Minimal-Diff Editing)

## 6. คลังขัดเกลาระดับประโยค (Sentence-Level Transcreation)

> 📂 ตัวอย่างเต็ม (ก่อน ➔ หลัง พร้อมเทคนิค): `data/transcreation.json`

เมื่อขัดเกลาประโยคให้เป็นวรรณศิลป์ ใช้ taxonomy เทคนิคนี้ (แต่ละตัวอย่างในคลังระบุ technique กำกับ):

| เทคนิค | ใช้เมื่อ | ตัวอย่างสั้น |
| :--- | :--- | :--- |
| **ตัดประธาน/กรรมซ้ำ** | อังกฤษทวน he/his/him ที่ไทยไม่ต้อง | "ดาบของเขา เขาไม่พูด" ➔ "...โดยไม่กล่าววาจา" |
| **ตัดคำเชื่อมทุกตัว** | MT แปล and/then ทุกคำ | "หันและเดินและเปิด" ➔ "หันหลังเดินไปเปิด" |
| **Passive ➔ Active** | ได้ถูก/โดย ทำให้ฉบับ | "ถูกทำลายโดยมังกร" ➔ "มังกรทำลาย" |
| **ตัดโครง There is/It is** | MT แปลโครงว่างของอังกฤษ | "มีบางสิ่งที่ฉันต้องบอก" ➔ "มีเรื่องต้องบอก" |
| **ปรับจังหวะขาดห้วง** | บทพูดสะเทือนใจ/หมางเย็น | "ฉันไม่รู้ อาจจะ" ➔ "ไม่รู้สิ... อาจจะ..." |
| **ถ่ายทอดน้ำเสียงประชด** | คำชมที่จริงคือคำด่า | "ยอดเยี่ยม" ➔ "ดีแล้ว... ต้องการพอดีเลย" |
| **แปล idiom เป็นสำนวนไทย** | take it or leave it ฯลฯ | "รับมันหรือปล่อยมัน" ➔ "รับหรือไม่รับ ตัดสินเถอะ" |
| **ปรับสรรพนามตามบริบท** | เชื่อมเสาหลัก 1 | ศัตรู: ข้า-แก / ระบบ UI: คุณ |

**ข้อควรระวัง:** `polished` ในคลังคือ *แบบอย่างหนึ่ง* ไม่ใช่คำตอบเดียว — งานขัดเกลามีอิสระถ้ายังครบความหมาย modality และบุคลิกตามหลักการแปลกลาง (ส่วนที่ 4) | การตัดสินให้ผ่านเกณฑ์: อ่านออกเสียงแล้ว "เข้าปาก" และผู้พูดนั้นพูดได้จริงตามบุคลิกของเขา

## 5. ระดับภาษาตามประเภทข้อความ (Message-Type Register Matrix)

| ประเภทข้อความ | แนวทาง |
| :--- | :--- |
| บทสนทนา | รักษาบุคลิก อารมณ์ ฐานะ และความสัมพันธ์ของผู้พูด — ห้ามทำให้ทุกตัวละครพูดสั้น/ดุดัน/หยาบเหมือนกัน |
| ตัวเลือกบทสนทนา | สื่อเจตนาชัด ไม่เปลี่ยนน้ำหนักจนผู้เล่นเข้าใจผิด (ดูหลักการแปลกลางข้อ 4) |
| บันทึกภารกิจและคำบรรยาย | อ่านลื่น กระชับ รักษามุมมองและน้ำเสียงผู้เรียง รวมถึงการประชดที่ต้นฉบับมี |
| หนังสือ จดหมาย ประกาศ | แยกระดับภาษาตามผู้เขียน (ชาวบ้าน/นักบวช/นักวิชาการ/เจ้าหน้าที่) — ละเอียดที่ `references/pillar-7-codex-readables.md` |
| คำอธิบายมอนสเตอร์/สารานุกรม | คงบรรยากาศตำนานและข้อมูลที่ใช้สืบสวน/ต่อสู้ ไม่เติมจุดอ่อนหรือประเภทที่ต้นฉบับไม่ได้ระบุ |
| ทักษะ อุปกรณ์ กลไก | ความแม่นยำของกลไกมาก่อนลีลา — แยกประเภททรัพยากร/ไอเท็ม/เงื่อนไขให้ชัด ห้ามรวมสิ่งที่ทำงานต่างกันเป็นคำเดียวเพื่อให้สั้น |
| UI เมนู การตั้งค่า บทช่วยสอน | ภาษาตรง เข้าใจง่าย ตามเสียงของระบบ (`data/pronouns-matrix.json` → `system_voice`) — ห้ามฝืนภาษายุคกลาง/สำนวนตัวละคร |
| ข้อความประชาสัมพันธ์ | ชวนอ่านตามน้ำเสียงต้นฉบับ ไม่เพิ่มสรรพคุณหรือข้อเสนอเอง |
