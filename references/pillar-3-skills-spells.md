# เสาหลักที่ 3: พิธีสารการแปลสกิลและทักษะต่อสู้ (Skill, Spell & Combat Phrase Protocol)

> 📂 ข้อมูลฉบับเต็ม: `data/mt-traps.json` (category: `skill-name`, `skill-mechanics`) + `data/transliteration.json`

## 1. การค้นคว้าบริบทเชิงลึกก่อนแปล (Mandatory Lore & Animation Research)

AI และผู้แปลต้องตรวจสอบบริบทของเกม คลาสตัวละคร ธาตุที่ใช้ และแอนิเมชันของสกิลก่อนแปลเสมอ ห้ามแปลเดาสุ่ม

## 2. ชื่อสกิลแฟนตาซีสั้นๆ ➔ วลีผสม 2-6 พยางค์ (Compound Phrasing)

หากเป็นชื่อสกิลสั้น (1-3 คำภาษาอังกฤษ) ให้แปลเป็น **"วลีผสมสั้นๆ 2-6 พยางค์"** ที่ทรงพลัง กระชับ และเห็นภาพการเคลื่อนไหว แทนการแปลยาวทื่อๆ:

- `Whirlwind Slash` ➔ **"ดาบวายุหมุน"** / **"ฟันรอบทิศ"** (❌ "การฟันลมกรด")
- `Shield Drum` ➔ **"เคาะโล่ท้าทาย"** (❌ "กลองโล่")
- `Shadow Dance` ➔ **"ระบำเงา"** / `Divine Retribution` ➔ **"ทัณฑ์เทวา"**

## 3. การทับศัพท์ชื่อเฉพาะและเวทมนตร์ (Proper Nouns & Mythological Spells)

หากเป็นชื่อเฉพาะ เทวตำนาน หรือคำศัพท์เฉพาะที่ไม่มีคำแปลตรงตัว ให้ใช้ **การทับศัพท์ภาษาไทยที่ถูกต้อง** ห้ามแปลแถไปเรื่อยจนความหมายเพี้ยน:

- `Ragnarok` ➔ **"แร็กนาร็อค"** / `Gungnir` ➔ **"กุงเนียร์"** / `Cintamani Stone` ➔ **"ศิลาจินดามณี"**
- คลังเต็ม: `data/transliteration.json`

## 4. บัญชีดำคำแปลกลไกสกิลผิดมหันต์ (Gaming Mechanics Anti-MT Blunder Blacklist)

🛑 กฎกลาง: ศัพท์กลไกเกมต้องแปลตามความหมายเชิงระบบ ห้ามแปลตามความหมายพจนานุกรมทั่วไป ตัวอย่างสำคัญ (รายการเต็มใน data file):

- 🛑 `Strike` ➔ `ฟาดฟัน / จู่โจม / ประหาร` (❌ "นัดหยุดงาน" / "ประท้วงหยุดงาน")
- 🛑 `Cooldown` ➔ `คูลดาวน์ / เวลารอใช้ใหม่` (❌ "เย็นลง" / "การระบายความร้อน")
- 🛑 `Cast / Casting` ➔ `ร่าย / กำลังร่ายเวท` (❌ "หล่อโลหะ" / "คัดเลือกนักแสดง")
- 🛑 `Respawn` ➔ `เกิดใหม่ / จุดเกิดใหม่` (❌ "วางไข่" / "การฟักตัว")
- 🛑 `Leap of Faith` ➔ `ดิ่งพสุธา (Leap of Faith)` (❌ "การก้าวกระโดดแห่งศรัทธา")
- 🛑 `Counter Kill / Combo Kill` ➔ `สังหารสวนกลับ / สังหารต่อเนื่อง` (❌ "เคาน์เตอร์คิล / คอมโบคิล")
