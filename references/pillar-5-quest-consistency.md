# เสาหลักที่ 5: สารบบชื่อเควสและความสอดคล้อง 100% (Quest Log Consistency Protocol)

> 📂 บัญชีดำชื่อเควสต์ฉบับเต็ม: `data/mt-traps.json` (category: `quest-title`, `quest-rule`)

## โครงสร้างไฟล์เควสต์ใน Game Engine

```
[เช่น RE Engine quXXXXXX_log หรือ Anvil DNA Tracker]
├── Title Row (_log_title / EXACT_TITLE)    ➔ ชื่อที่แสดงในเมนูเควสต์ล็อก / DNA Tracker
├── Completed Row (Completed: <Title>)      ➔ แบนเนอร์แจ้งเตือนตอนจบเควสต์สำเร็จ
├── Failed Row (Failed: <Title>)            ➔ แบนเนอร์แจ้งเตือนตอนจบเควสต์ล้มเหลว
└── Task & Remind Rows (_log_task_...)      ➔ คำอธิบายเป้าหมายและบันทึกเหตุการณ์
```

## กฎเหล็ก

1. **ความสอดคล้องระดับอักขระ (Strict Character-for-Character Matching):** ชื่อเควสต์ในเมนู (`_log_title` / DNA Tracker) และชื่อหลังคำว่า `"สำเร็จ: "` / `"ล้มเหลว: "` **ต้องตรงกัน 100% ทุกตัวอักษร** ห้ามชื่อเมนูอย่างหนึ่งแต่แบนเนอร์อีกชื่อหนึ่งเด็ดขาด
2. **ภารกิจหลายตอน (Multi-Part Quest Pair Harmonization):** ภารกิจที่มีหลายตอน (Part 1 & Part 2, Signs and Symbols I-III) ต้องใช้วิธีแปลและระดับภาษาเดียวกัน 100% — ห้ามตอนที่ 1 ทับศัพท์แล้วตอนที่ 2 แปลความหมาย (เช่น `ดีคอน ตอนที่ 1` แต่ `ท่านสังฆานุกร ตอนที่ 2` หรือ `เดอะ เซนติเนล ตอนที่ 1` แต่ `ผู้พิทักษ์ ตอนที่ 2`) และห้ามปะปนรูปแบบการนับตอน ต้องใช้ **`ตอนที่ 1 / ตอนที่ 2 / ตอนที่ 3`** สม่ำเสมอทั้งเกม
3. **ห้ามแปล `ESCAPE` เป็นปุ่ม `Esc`:** ในบริบทชื่อภารกิจหลบหนี หัวข้อคู่มือการเล่น หรือแบนเนอร์แจ้งเตือน ต้องแปลว่า **`การหลบหนี`** เสมอ
4. **ชื่อสถานที่ลับและโบราณสถาน:** โบราณสถานขนาดมหึมา (เช่น `Cistern`) ห้ามลดทอนสเกลเป็น "ถังเก็บน้ำ" ให้แปลตามสเกลประวัติศาสตร์ **`อุโมงค์ส่งน้ำ / อุโมงค์เก็บน้ำใต้ดิน`** | ชื่อลานจัตุรัส (เช่น `Forum of the Ox`) ต้องรวมการแปลสะเปะสะปะให้เป็นหนึ่งเดียว (**`จัตุรัสฟอรัมแห่งวัว`**)
5. **แบนเนอร์จบ Sequence (Sequence Completion Banner Alignment):** ต้องใช้โครงสร้างคำนำหน้าเดียวกันทั้งเกม เช่น `ซิงค์ความทรงจำ: ลำดับที่ %d เสร็จสมบูรณ์` (ห้าม Sequence ใดหลุดเป็น `ความทรงจำซิงค์แล้ว:...`)
6. **Subject 16/17 Lore Consistency:** ในบริบทมนุษย์ทดลองพันธุกรรม (เช่น Abstergo Animus) `Subject 16` ต้องแปลว่า **`ตัวทดลองที่ 16 / ร่างทดลองที่ 16`** (❌ "เป้าหมายที่ 16" / "หัวข้อสิบหก")
7. **Quest Objective Term Alignment:** คำศัพท์ บุคคล และไอเท็มในคำอธิบายเป้าหมาย ต้องตรงกับชื่อทางการใน Glossary เสมอ (หากตัวละครคือ *นายกองเสบียง* ห้ามหลุดเป็น *ส่งจดหมายให้เสบียงกรัง*)
8. **ชื่อเควสต์สำนวนพื้นบ้าน:** ดูบัญชีดำเต็มใน data file — ตัวอย่าง: `Creature Comforts` ➔ **"สิ่งอำนวยความสุขสำราญ"** (❌ "ความสบายของสัตว์ประหลาด"), `Scooped!` ➔ **"ชิงข่าวเด็ด!"** (❌ "ตักมาแล้ว!"), `The GOAT Pen` ➔ **"คฤหาสน์โกทเพน"** (❌ "คอกแพะ")
9. **Missing Person Quests:** ใช้คำนำหน้ามาตรฐานเดียวกัน 100% ทั้งโปสเตอร์ กระดานงาน และสมุดเควสต์: **`คนหาย: [ชื่อบุคคล]`** (❌ ปะปน "สูญหาย" / "หายตัว")
10. **DLC Entitlement Prerequisite References:** ข้อความเงื่อนไขปลดล็อกสิทธิ์ DLC/อาวุธ (เช่น 'หลังจากทำเควส "..." สำเร็จ') ต้องตรงกับชื่อเควสต์ที่แปลจริงทุกตัวอักษร 100% ห้ามหลุดชื่อเก่าหรือภาษาอังกฤษค้าง
